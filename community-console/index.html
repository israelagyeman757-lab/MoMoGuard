COMMUNITY CONSOLE · TRACK 4 PIVOT

Report, review, and publish — together.

This page talks only to the real controller's community endpoints (/reports, /numbers/check, /warnings) — it scores nothing itself. A report is pending until a moderator reviews it here; only a published report becomes a warning that shows up on GET /warnings and in the feature phone's "Scam Alerts" and "Check a Number" menus. This is additive to the existing payment-risk system (Brain, pause manager, MTN sandbox bank plug, Message Intelligence Agent), which is unchanged and still running underneath.

Checking connection…

1 · Submit a community report

Anyone can report a number as suspected. One report per reporter per number per day. A report alone is never proof — it only becomes a public warning once a moderator publishes it below.

2 · Moderator review queue

Every report ever submitted, newest first. Publish turns a report into a warning everyone can see; reject drops it without creating one. No login — anyone with this page's URL can moderate, a deliberate hackathon-scope simplification (see README).
